# Retro Shelf

Небольшой учебный интернет-магазин ретро-консолей. Проект сделан на обычных HTML, CSS и JavaScript без CSS-фреймворков.

## Страницы

- `index.html` — главная страница, преимущества и карусель популярных товаров.
- `catalog.html` — каталог консолей, комплектующих и аксессуаров.
- `product.html` — карточки товаров, открываемые по ссылкам из каталога.
- `order.html` — форма заявки.
- `contacts.html` — контактная информация.

## Запуск

Откройте `index.html` в браузере. Для публикации загрузите содержимое папки проекта на статический хостинг.

## Структура

- `css/style.css` — стили сайта.
- `js/main.js` — карусель, мобильное меню и демонстрационная обработка формы.
- `images/` — фотографии товаров.

Форма показывает подтверждение в браузере; отправка заявок на сервер не подключена.
